# System Requirements

System Requirements mendefinisikan batasan teknis dan prasyarat lingkungan agar sistem dapat berjalan dengan baik.

## 1. Arsitektur Sistem
Sistem dibangun berbasis web (*Web-based Application*) dengan arsitektur Client-Server.

## 2. Kebutuhan Perangkat Keras (Hardware)

### Server (Deployment)
*   **Processor**: Minimal Dual Core 2.0 GHz
*   **RAM**: Minimal 4 GB (Disarankan 8 GB)
*   **Storage**: Minimal 50 GB SSD
*   **Koneksi Internet**: Bandwidth minimal 10 Mbps (Dedicated)

### Client (Perangkat Pengguna - Admin/Pustakawan)
*   **Perangkat**: PC Desktop atau Laptop
*   **Layar**: Minimal resolusi 1366 x 768 pixel
*   **Periferal**: Barcode Scanner (USB/Bluetooth) untuk input buku/KTM.

### Client (Pengguna - Mahasiswa)
*   Dapat diakses melalui Laptop, Tablet, atau Smartphone.

## 3. Kebutuhan Perangkat Lunak (Software Environment)

*   **Sistem Operasi Server**: Linux (Ubuntu 20.04 LTS) atau Windows Server 2019.
*   **Web Server**: Nginx atau Apache HTTP Server.
*   **Database Server**: MySQL 8.0 atau PostgreSQL 13.
*   **Bahasa Pemrograman (Backend)**: PHP 8.1 / Node.js 16+.
*   **Browser**: Kompetibel dengan Google Chrome 90+, Firefox 88+, Microsoft Edge (Chromium).
