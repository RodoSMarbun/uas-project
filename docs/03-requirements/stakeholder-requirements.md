# Stakeholder Requirements (SR)

Stakeholder Requirements menerjemahkan kebutuhan bisnis ke dalam bahasa yang lebih spesifik berdasarkan perspektif setiap pemangku kepentingan.

## Daftar Stakeholder

1.  **Kepala Perpustakaan**: Penanggung jawab operasional perpustakaan.
2.  **Staf Pustakawan**: Operator harian sistem (Front Office & Back Office).
3.  **Mahasiswa & Dosen (Anggota)**: Pengguna layanan perpustakaan.
4.  **Bagian IT / Admin Sistem**: Pengelola teknis sistem.

## Requirement List

| ID | Stakeholder | Deskripsi Kebutuhan | Prioritas |
| :--- | :--- | :--- | :--- |
| **SR-01** | Kepala Perpus | Saya ingin melihat laporan denda yang terkumpul setiap bulan untuk keperluan audit keuangan. | **Should Have** |
| **SR-02** | Pustakawan | Saya ingin sistem memberitahu jika seorang anggota mencoba meminjam tapi masih memiliki tanggungan buku yang belum kembali. | **Must Have** |
| **SR-03** | Pustakawan | Saya ingin bisa mencetak label barcode untuk buku baru agar mudah dipindai. | **Could Have** |
| **SR-04** | Mahasiswa | Saya ingin bisa mencari letak rak buku tertentu agar tidak bingung saat mencari di perpustakaan. | **Should Have** |
| **SR-05** | Mahasiswa | Saya ingin mendapatkan notifikasi email jika masa peminjaman buku saya akan segera habis. | **Could Have** |
| **SR-06** | Admin IT | Saya ingin bisa mereset password pengguna yang lupa kata sandinya. | **Must Have** |
