# User Journey Map


## Skenario: Mencari dan Meminjam Buku

**Aktor**: Enrico (Mahasiswa)
**Goal**: Meminjam buku "Akuntansi Dasar" untuk tugas kuliah.

| Tahapan | Aktivitas Pengguna | Titik Sentuh (Touchpoint) | Emosi / Pikirannya | Peluang Sistem |
| :--- | :--- | :--- | :--- | :--- |
| **1. Awareness** | Enrico sadar butuh buku referensi untuk tugas besok. | Pikiran sendiri | "Duh, tugas deadline lusa. Cari di perpus ah." (Cemas) | Kirim notifikasi buku baru via email. |
| **2. Search** | Buka Info Perpus di HP, ketik judul buku. | Smartphone (Web App) | "Semoga ada bukunya." -> "Ketemu! Stok ada 2." (Senang) | Fitur pencarian *autocomplete* yang cepat. |
| **3. Locate** | Pergi ke perpustakaan menuju Rak 3B sesuai info di web. | Rak Buku Fisik | "Mana ya... Nah ini dia." (Fokus) | Peta lokasi rak digital di aplikasi. |
| **4. Borrow** | Membawa buku ke meja sirkulasi, memberikan KTM. | Meja Sirkulasi (Barcode Scanner) | "Semoga antrian gak panjang." | Self-service kiosk atau scan cepat via HP. |
| **5. Use** | Membaca buku di rumah. | Buku Fisik | "Bukunya lengkap, untung dapet." (Puas) | - |
| **6. Return** | Mengembalikan buku sebelum jatuh tempo. | Meja Sirkulasi | "Oke, balikin sekarang biar gak kena denda." (Lega) | Notifikasi pengingat H-1. |
